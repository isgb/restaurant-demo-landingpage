# 🍽️ Restaurant Landing Page

Landing page moderna y responsiva para un restaurante, diseñada para mejorar la presencia online y facilitar que los clientes conozcan el menú, ubicación y formas de contacto.

---

## 🧩 Características

- 📱 Diseño completamente responsivo (mobile-first)
- 🍔 Sección de menú con imágenes, descripciones y precios
- 📍 Integración de ubicación mediante Google Maps
- ⏰ Horarios de atención
- 📞 Botón de contacto directo
- 🎨 Interfaz moderna utilizando Bootstrap
- ⚡ Navegación fluida y estructura clara

---

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
